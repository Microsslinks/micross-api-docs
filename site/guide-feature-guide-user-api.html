操练场在线测试

操练场是内置的在线测试工具，无需编写代码即可直接与模型对话，适合快速验证令牌是否可用。

访问操练场

左侧导航点击「操练场」，或直接访问 /console/playground

使用操练场

  1. 在左侧选择要测试的模型
  2. 在底部输入框输入消息内容，点击发送
  3. 右侧对话区域显示模型的回复结果

获取 API 地址

复制 API 地址

  1. 访问平台首页
  2. 在页面中部找到 API Base URL 显示区域
  3. 点击复制按钮，将地址复制到剪贴板

配置客户端

将复制的地址填入你的客户端或代码中作为 base_url，配合令牌即可开始调用。
